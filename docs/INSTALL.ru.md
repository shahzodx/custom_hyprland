# Arch + Hyprland dotfiles

Конфигурация рабочего стола: Hyprland, Waybar, Kitty, Wofi, Rofi, Dunst,
Hyprlock, Hypridle, GTK и Qt. Тёмное оформление, палитра под обои, центр
управления, таймер, задачи и локальная статистика приложений.

Сборка подготовлена 6 ноября 2026 года. Скриншоты и стартовая палитра обновлены в тот же день. Исходное окружение: Arch Linux,
Hyprland 0.57.0, Waybar 0.15.0, Matugen 4.2.0, awww 0.12.1.
Конфиг Hyprland использует Lua; ориентир — установленная версия 0.57.
Описание формата: [официальная документация Hyprland](https://wiki.hypr.land/configuring/core/).

## Установка

Перенеси **всю эту папку** на нужный компьютер, например в `~/dotfiles`.
Для самого установщика нужны Bash и Python 3. Запускай его от обычного
пользователя, без `sudo`.

```bash
cd ~/dotfiles

# Посмотреть заменяемые файлы; ничего не записывает
./install.sh --dry-run

# На чистом Arch: отдельно установить пакеты и обновить систему
./install.sh --packages

# Установить конфиги с автоматическим выбором мониторов
./install.sh
```

Для сохранения твоей исходной схемы ноутбука вместо последней команды:

```bash
./install.sh --profile laptop
```

Профиль `laptop`: eDP-1 1920×1080@59.93, масштаб 1.5; HDMI-A-1 зеркалирует
встроенный экран, 1920×1080@60, масштаб 1.5. Стандартный профиль `portable`
использует preferred mode и автоматический масштаб. Настройки находятся
в `~/.config/hypr/monitors.lua`; названия выходов показывает `hyprctl monitors`.

После установки выйди из сессии Hyprland и войди снова, чтобы запустились
все фоновые программы. Сохранение конфига может вызвать автоматическую
перезагрузку настроек в уже открытой сессии.

На новой системе службы можно включить отдельно, если они ещё не работают:

```bash
sudo systemctl enable --now NetworkManager.service bluetooth.service
```

Установщик конфигов не устанавливает пакеты и не включает службы.
Команда `--packages` отдельно вызывает `sudo pacman -Syu --needed`;
список можно отредактировать в `packages.txt`, pacman запрашивает подтверждение.
Пакеты проверены по локальной базе репозиториев Arch при подготовке сборки.
Если уже установлен `swayosd-git`, убери `swayosd` из списка либо разреши
конфликт вручную. Необязательный `wlogout` устанавливается отдельно; его
конфиг включён, но основной сетап его не запускает.

## Резервная копия и откат

Перед изменениями установщик копирует каждый заменяемый файл в:

```text
~/.local/state/arch-hyprland-dotfiles/backups/<дата-время-id>/
```

Полный путь выводится после установки. Можно предварительно посмотреть откат:

```bash
./install.sh --restore ~/.local/state/arch-hyprland-dotfiles/backups/ИМЯ-КОПИИ --dry-run
./install.sh --restore ~/.local/state/arch-hyprland-dotfiles/backups/ИМЯ-КОПИИ
```

Откат возвращает прежние файлы и симлинки, удаляет файлы, которых раньше не было.
Текущие версии сохраняются внутри этой копии в `before-restore/`. Пустые созданные
каталоги могут остаться. Пакеты и службы откат не меняет. Для нескольких установок
откатывай копии в обратном порядке. При ошибке записи во время установки
установщик пытается выполнить откат автоматически; при аварийном отключении
можно использовать напечатанный манифест из каталога резервных копий.

Файлы с одинаковым содержимым и правами не переписываются. Существующие
`~/Pictures/wallpapers/dotfiles-default.png`, личные базы Waybar и остальные файлы
за пределами списка установки сохраняются. Отдельный файл-симлинк архивируется
и заменяется копией; при симлинке на родительскую папку установщик останавливается
до записи конфигов, чтобы не затронуть другой каталог.

## Что включено

- `config/hypr/` — Lua-конфиг, горячие клавиши, блокировка, настройки сна,
  уплотнение рабочих пространств, графические ресурсы.
- `config/waybar/` — панель, центр управления, переключение обоев, Matugen,
  таймер, задачи, статистика, CSS, иконки и тесты существующих утилит.
- `config/kitty/`, `config/wofi/`, `config/dunst/` — терминал, меню и уведомления.
- `config/gtk-3.0/`, `config/gtk-4.0/`, `config/qt6ct/`, `config/fontconfig/` —
  цвета и шрифты приложений.
- `config/fastfetch/`, `config/wlogout/` — дополнительные конфиги.
- `assets/wallpaper.png` — твои исходные обои, копируются только при отсутствии
  файла `dotfiles-default.png` на целевой машине.
- `profiles/laptop/` — исходная схема экранов.
- `install.sh`, `scripts/install.py` — установка, предпросмотр и откат.

Старые `.bak`, SQLite-базы задач и статистики, состояние таймера, кэш,
логи, настройки браузеров, аккаунты и личная аватарка исключены.
Установленные утилиты задач и статистики создают новые локальные базы при работе.
Это снимок файлов: дальнейшие изменения действующего сетапа не попадут сюда
автоматически.

## Горячие клавиши

`Super` — клавиша Windows.

| Сочетание | Действие |
| --- | --- |
| Super + Q | Kitty |
| Super + R | Меню приложений |
| Super + E | Dolphin |
| Super + B | Firefox |
| Super + W | Обои и генерация палитры |
| Super + L | Блокировка |
| Super + C | Закрыть окно |
| Super + V | Плавающее окно |
| Super + 1…0 | Рабочее пространство |
| Super + Shift + 1…0 | Перенести окно |
| Super + стрелки | Фокус окна |
| Super + S | Скрытое пространство |
| Print | Выделенная область в буфер |
| Shift + Print | Скриншот в Pictures/Screenshots |
| Alt + Shift | Английская / русская раскладка |

## Настройка и проверка

Добавляй обои в `~/Pictures/wallpapers`. `Super + W` выбирает изображение,
Matugen обновляет цвета Waybar, GTK, Qt, Kitty и Dunst. Некоторые Qt-приложения
потребуется открыть заново. Hyprlock использует выбранные обои через
`~/.cache/current-wallpaper`; ссылка создаётся при запуске обоев.

Основные программы и клавиши меняются в `config/hypr/hyprland.lua`, модули
панели — в `config/waybar/config.jsonc`, пакеты — в `packages.txt`. В исходниках
`@HOME@` — шаблон: установщик заменяет его домашним каталогом целевого пользователя.
Исходные шаблоны с этим маркером не предназначены для прямого запуска.

Поддерживаются стандартные пути `~/.config`, `~/.cache`, `~/Pictures/wallpapers`.
Путь домашней папки: латиница, цифры, `/`, `.`, `_`, `-`, без пробелов и спецсимволов
(пути встраиваются в команды и разные форматы конфигов).
Часовой пояс статистики приложений берётся из `/etc/localtime`.
Hyprpaper-конфиг сохранён для справки; обои в автозапуске обслуживает awww.

Проверить установку в отдельном каталоге, не меняя текущий рабочий стол:

```bash
mkdir -p /tmp/dotfiles-preview-home
./install.sh --home /tmp/dotfiles-preview-home --dry-run
./install.sh --home /tmp/dotfiles-preview-home
python3 -B -m unittest discover -s tests -v
python3 -B -m unittest discover -s config/waybar/tests -v
```

Здесь установщик и файловые операции проверяются отдельно. Внешний вид на
другом GPU, мониторе или версии программ потребует проверки в самой сессии.
