Сняты в настоящей сессии Hyprland через `grim`: терминал и задачи —
6 ноября 2026 года; рабочий стол, меню Wofi и панель Waybar обновлены
7 ноября 2026 года. Полные снимки — 1920×1080; полоса Waybar — 1920×45.
Масштаб экрана — 1.5.

Терминал показывает реальную системную информацию без имени пользователя и
хоста. Строка установщика под ней — демонстрация команды и возможностей,
а не полный вывод установки. Личные окна, задачи и история не снимались.

Для повторной съёмки из корня репозитория:

```bash
python3 -B scripts/capture-screenshots.py
```

Требуются работающая сессия Hyprland, `hyprctl`, `grim`, `kitty`, `fastfetch`,
`wofi`, `dunstctl`, Python и GTK-зависимости из `packages.txt`.
Применяется оформление установленной сессии; терминал и виджеты используют
конфиги из этой папки. Скрипт временно переключает рабочее пространство и
приостанавливает уведомления, затем возвращает прежний фокус и режим уведомлений.
Запускай его в момент, когда переключение рабочего пространства не помешает работе.
